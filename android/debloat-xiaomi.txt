# Packages disabled on the reference TV: Xiaomi MiTV-MOOR4 (venom), Google TV / Android 11.
# One package per line; # starts a comment. Nothing is uninstalled: each one is disabled for user 0
# and comes back with `pm enable`. docs/android-xiaomi.md has the commands to apply and undo the list.
#
# Based on debloat.txt from CleanXiaomiTV (https://github.com/majnioui/CleanXiaomiTV), MIT, which keeps
# its reasons per package. The additions here are marked "added".
#

# HDMI inputs), com.mediatek.tvinput and com.mediatek.tv.service (HDMI picture and sound), mitv.service,
# com.xiaomi.mitv.scenemode (game mode), com.xiaomi.android.tvsetup.partnercustomizer (the remote's Input
# and Settings buttons), Bluetooth (the remote), Play Store and Play services, Gboard, WebView.
# The Google TV launcher and the setup wizard are handled in docs/android-xiaomi.md, not here.
